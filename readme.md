# Nativewind Expo Example

A simple example of how to use Nativewind in an Expo project.

## Installation

1. Clone the repository
2. Install dependencies with `npm install` or `yarn install`
3. Start the development server with `npm start` or `yarn start`

## Usage

1. Open the app in Expo Client on your device
2. You should see a blue button that says "Press Me"
3. Press the button to see an alert

## Configuration

This project uses the following configuration:

* `nativewind.config.js`: This file is used to configure Nativewind.
* `tailwind.config.js`: This file is used to configure Tailwind CSS.
* `babel.config.js`: This file is used to configure Babel.
* `webpack.config.js`: This file is used to configure Webpack.
